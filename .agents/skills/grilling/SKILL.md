# Grilling

Interview the user relentlessly until both sides share a precise understanding. Walk the decision tree branch by branch, resolving dependencies one at a time. For every question, include your recommended answer and the reasoning that makes it preferable.

Ask exactly one decision question at a time and wait for the answer before continuing. If a fact can be established from repository files, tools, or other available evidence, investigate it instead of asking. Decisions remain the user's: present each one and wait.

Do not implement the plan or make the proposed change until the user confirms that the shared understanding is complete.
