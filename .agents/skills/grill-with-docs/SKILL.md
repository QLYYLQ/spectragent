# Grill With Domain Documents

Read and combine [the grilling workflow](../grilling/SKILL.md) with [the domain-modeling workflow](../domain-modeling/SKILL.md).

Ask one decision question at a time. As terminology or architectural decisions become settled, maintain the repository documents according to the domain-modeling rules. Do not implement the underlying plan until the user confirms that the shared understanding is complete.
